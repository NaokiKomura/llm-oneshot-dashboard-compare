わかったこと

  • gpt-6-astraは時間もコストも最小だった(247秒、約$0.75)。Opus 5.5は約2.2倍の552秒かかった。
  • 待ち時間の差は思考の量から来ている。最初の文字が出るまで、astraは21秒、Opus 5.5は280秒だった。
  • 作り込む方向がモデルごとに違う。Opus 5.5とFable 5.1は分析機能を足し、Argonは示唆の文章と推奨アクションを足し、astraは頼まれた範囲で止めた。
  • ダミーデータの持ち方も違う。astraとFable 5.1は個別投稿を数万件生成して集計し、Argonは全値を手で書いた(投稿は27件)。
  • 1発の出力は動かないことがある。Fable 5.1は変数の二重宣言で画面全体が動かず、比較の最初に動作確認が必要だと分かった。

モデルごとの使いどころ

今回の1回の出力から見た使い分けであり、一般的な性能評価ではない。

Gemini 4 Argon

実行したプロンプト

4モデルに渡した全文。改変していない。

# タスク
Xポストのダミーデータを作成して、発話トピック等の分析を行うダッシュボードの作成
# 機能的な要求
- マクロ〜ミクロ様々な粒度感で分析可能（例：「ゲーム」→「コンシューマーゲーム」→「任天堂スイッチ」→「マリオカートワールド」のような形で粒度感を遷移させつつそれぞれの粒度感で多面的なデータの可視化ができる）
- 発話量の推移から発話トピック・含まれるインサイトなど多面的な示唆を可視化
# アウトプット
例として、ゲームのトピックで多面的に発話傾向を表すダッシュボードのモックを作成。HTMLファイルで出力。

実行条件

  • gpt-6-astraはOpenAI Responses API、Fable 5.1とOpus 5.5はAnthropic Messages APIで呼んだ。
  • どれもストリーミングで呼び、思考の強さは指定せず既定のまま動かした。Opus 5.5の既定はmediumである。
  • 各モデル1回だけ実行し、再実行や手直しはしていない。
  • ArgonはAPIキーもVertex AIの権限もなく、AI Pro枠のAntigravity CLIでも選べなかった。利用者が別経路で生成したHTMLを取り込んだ。

この比較の限界

  • 各モデル1回ずつの出力で、再実行すれば結果は変わりうる。
  • 評価はコードの集計と初期表示の画面に基づく。すべての操作を手で確かめてはいない。
  • Claude側の「最初の出力まで」には思考時間が含まれる。
  • Argonは条件が異なるため、時間とコストを比べられない。

コード、生の出力、計測値は GitHubのリポジトリ にある。
